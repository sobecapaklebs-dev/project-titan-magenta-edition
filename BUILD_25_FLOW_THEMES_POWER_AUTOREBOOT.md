# Project Titan Magenta Edition RC14 — Build 25

Base reconciled from the BuildFix34 Snake Flow branch and the previously approved BuildFix33 Flow-variants/theme-selector branch.

## Scope implemented

Only the requested areas were changed:

1. All Flow themes use the same head-driven Snake Flow motion model.
2. The approved Orbis-style theme selection screen is restored.
3. PS2 shutdown and console restart are implemented as real power-transition paths.
4. Every successful system `.pup` update automatically enters the console-restart path.
5. Build identifier is 25.

## Power actions

### Turn Off PS2

The shutdown path now:

1. enters the existing single-owner storage mode;
2. waits for the storage worker to acknowledge that it is parked;
3. loads the PS2SDK `poweroff.irx` server from the embedded EE buffer;
4. shuts down browser/network activity;
5. plays the shutdown sound and closes audio/input clients;
6. calls the PS2SDK software power-off RPC.

If storage cannot be quiesced or the power-off server cannot be initialized, shutdown is cancelled and an error is shown instead of forcing a risky power transition.

### Restart Project Titan

The existing Titan hot re-exec path remains unchanged.

### Restart PS2

The console restart path now:

1. quiesces storage;
2. closes browser/audio/input EE clients;
3. shuts down the Titan IOP service manager;
4. performs the existing bounded IOP reset + sync bootstrap;
5. transfers control to ROM `OSDSYS`.

The Power Options page and context menu both map this action consistently to row 2.

## `.pup` automatic restart

On successful `TitanSystemUpdate` completion, storage ownership remains exclusive and the shell immediately enters the same console-restart path. Failed or cancelled updates do not restart and return to the running shell normally.

The updater remains forward-only and its no-downgrade comparison was not removed or bypassed.

## Validation

The host contract suite passed, including profile/VMC, storage, Neutrino/UL, Package Installer, theme service, renderer, VU1/Flow contracts, transactional forward-only updater, wLaunchELF native port and the new Build 25 Flow/theme-selector/power/auto-reboot contract.

A PS2DEV EE/IOP toolchain is not installed in the artifact environment, so `kernel.elf`, the embedded real `poweroff.irx` header, and the final `.pup` binary were not cross-compiled here. They are generated by the Makefile on a PS2DEV host.

## Important numbering consequence

Because the requested build identifier is 25 and the existing updater intentionally rejects any package whose numeric build is less than or equal to the running build, a console already running a numeric BuildFix34 will reject a PUP whose TPUP build field is 25 as a downgrade. No downgrade bypass or hidden renumbering was added because that was outside the requested scope.
