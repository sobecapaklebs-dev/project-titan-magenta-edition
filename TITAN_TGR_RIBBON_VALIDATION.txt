1. TITAN GAME RUNTIME (TGR) v1
--------------------------------
New public ABI:
  kernel/include/titan_game_sdk.h
New runtime service:
  kernel/src/services/titan_game_runtime.[ch]
GoldenEye bridge:
  ports/goldeneye/titan_ge_platform.[ch]
  ports/goldeneye/README.md

Execution contract:
  - Separate from Titan App/.tmod ABI.
  - Game session parks the normal storage worker via a dedicated game-exclusive lane.
  - Stops Titan menu music during the game session and resumes it after restoration.
  - Game-owned 640x448 display mode, double framebuffer + dedicated Z16.
  - Rebuilds the previous shell video layout on exit.
  - Rebinds existing VU1 Ribbon video resources after the GS VRAM rebuild without allocating a second packet set.
  - Game heap: default 12 MiB, clamped 4..16 MiB, alignment 16..4096, 256 tracked allocations.
  - Input ABI exposes four logical pad slots. Current physical implementation polls PS2 ports 0 and 1; slots 2/3 are reserved for future multitap support.
  - External audio uses Titan's existing 32 kHz stereo signed-16 PCM stream.
  - Storage wrappers use TitanStorageIo 64-bit offsets/sizes.
  - MVP transform + indexed colored triangles are functional in the v1 bring-up backend.
  - PSM16 texture upload is functional.
  - IMPORTANT: textured triangle sampling is deliberately NOT advertised yet. Supplying a non-zero texture handle to indexed-triangle drawing returns -2. This is fail-closed until the GoldenEye GBI -> VU1/GS translator is implemented and hardware-validated.

Public feature bits currently advertised:
  TITAN_GAME_FEATURE_Z16
  TITAN_GAME_FEATURE_COLORED_TRIANGLES
  TITAN_GAME_FEATURE_TEXTURE_UPLOAD_P16
  TITAN_GAME_FEATURE_FOUR_PAD_ABI
NOT advertised:
  TITAN_GAME_FEATURE_TEXTURED_TRIANGLES
