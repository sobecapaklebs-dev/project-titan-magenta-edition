# Scarlet Flow

First installable Project Titan `.tthm` theme.

Retuned in BuildFix18 to match the user-supplied Flow reference video more closely: slower ribbons, broader arcs, reduced noise, and much milder navigation boost.

- ID: `SCARLETFLOW`
- shell API: 1
- background engine: `flow3d-v1`
- background: black
- flow: subtle translucent scarlet/red ribbons
- system behavior/input: unchanged

Build with the TPKG tool as a theme and use a `.tthm` output extension.
