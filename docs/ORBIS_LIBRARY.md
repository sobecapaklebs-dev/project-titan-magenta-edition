# Orbis-style Library

The Project Titan Library is the full catalog behind the limited Home carousel.

Visible categories follow the useful PS2 subset of the PS4 OrbisOS Library:

- Search
- All
- Folders
- Games
- Applications

`Purchased` is intentionally absent because Project Titan has no online store/purchase entitlement system.

Home is a presentation subset. Library is authoritative for browsing all catalogued folders, PS2 games and applications.
