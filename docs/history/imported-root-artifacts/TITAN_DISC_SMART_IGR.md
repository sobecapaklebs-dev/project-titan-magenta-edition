# Titan Disc + Smart IGR — BuildFix30

Physical-disc sessions use the same fail-closed compatibility philosophy as UL/Neutrino. The default profile is Return-only: PS/Home/Guide enters the resident Titan IGR path when the controller exposes System Button, while DS2 retains the existing Smart IGR chord. A title is promoted to MINIMAL or FULL only if a compatibility profile proves the resident CONTEXT2/GS restoration path safe.

Return invokes the resident Titan exit path and restores Titan through the normal boot/return architecture. Once the shell is restored, Theme lifecycle uses `RETURN_HOME`, not cold-start `PRE_HOME`, so the dynamic scene cannot appear before HOME restoration and does not replay the complete cold intro.
