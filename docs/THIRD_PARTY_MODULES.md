# Titan-branded derived modules

## Titan Neutrino Engine

A modified Neutrino derivative integrated with Project Titan profiles, VMC,
library discovery, strict handoff and fault handling. See the module `LICENSE`,
`UPSTREAM.md` and `TITAN_CHANGES.md`.

## Titan UL Engine

A modified Open PS2 Loader derivative used as the native UL execution backend.
It receives explicit Titan autolaunch and VMC arguments and has Titan-specific
resource cleanup and diagnostics. See its `LICENSE`, `CREDITS`, `UPSTREAM.md`
and `TITAN_CHANGES.md`.

These product names describe the maintained derivatives. Upstream names and
credits are preserved and no endorsement by upstream authors is implied.
