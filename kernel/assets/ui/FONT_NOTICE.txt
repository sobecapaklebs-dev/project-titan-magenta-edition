PROJECT TITAN UI FONT NOTICE

The bundled A8 atlas in this development package was rasterized from
Inter Display Medium, distributed under the SIL Open Font License 1.1.
The original OTF font is not included in this package.

The 0.3.5 atlas generator left-aligns glyphs inside their cells and emits
per-glyph draw widths plus pair-kerning metrics. This keeps proportional text
spacing stable in the 640x448 software renderer.

Titan UI 0.9.28 uses the previously empty final atlas cell for a deterministic
geometric U+2605 star. The original 95 ASCII cells, advance arrays and kerning
matrix remain in their existing positions.

SST is a commercial Monotype/Sony typeface and is not redistributed here.
To use a properly licensed local SST font in Project Titan, regenerate only
the raster atlas and metrics from your own installed font file:

  cd kernel
  python3 tools/generate_font_atlas.py --font /path/to/your/licensed/SST-Medium.otf
  make clean-generated
  make

The generator never copies the source OTF/TTF into the project.
