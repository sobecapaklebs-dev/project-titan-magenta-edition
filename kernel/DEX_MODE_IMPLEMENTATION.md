# DEX diagnostics and activity tiles

The DEX area exposes read-only runtime diagnostics, application scanning and
transfer/library activity. It does not advertise a bundled FTP server. Visible
labels use `★ APP_HOME` for the application shortcut and `★ FTP_HOME` for
transfer telemetry. FTP_HOME opens the activity diagnostics; this release does
not advertise a bundled FTP server.

DEX configuration is persisted through verified temporary/backup publication.
Unavailable BIOS/model probes are shown as unavailable rather than invented.
