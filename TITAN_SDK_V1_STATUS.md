# Titan SDK v1 Status — BF30

Public App/Game SDK headers are frozen and hash-tracked. Application Runtime, normalized input, network, graphics/audio and lifecycle surfaces retain BF29 compatibility. Theme v4 lifecycle is documented separately with PRE_HOME, HOME_ENTER, HOME, TOP, SUBMENU, HOME_EXIT and RETURN_HOME behavior.

Disc hardware ownership is intentionally not a general-purpose SDK feature. Advanced developers may receive future versioned Disc/session extensions, but Magenta v1 does not expose raw CD/DVD calls as a convenience API.

Host/API freeze is source-complete. R5900 target compilation of SDK examples remains an external PS2DEV gate.
