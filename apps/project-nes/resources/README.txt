Project Nes 0.1.5 Preview

A powerfull NES emulator for Project Titan.
Powered by: VlombisCore(TM) Technology

Included test ROM: data/roms/ProjectNesTest.nes
The included ROM is an original Project Nes diagnostic homebrew and contains no Nintendo game data.

Controls:
D-pad = NES D-pad
Cross = A
Circle = B
Start = Start
Select = Select
Triangle = Pause/Resume
Square = Reset
Select + Circle = Exit to Project Titan

Current preview target: iNES Mapper 0 (NROM).

Controles: D-pad=Nes, X=A, Circulo=B, Start/Select=NES, Triangulo=Pausa, Quadrado=Reset, Select + Circulo=Sair.
Preview 0.1: Mapper 0/NROM, PPU frame-based e APU inicial (pulse/triangle).
